# ПР02 — типы сообщений

## Команда движения

Полное имя топика: `/turtle1/cmd_vel`.
Тип: `geometry_msgs/msg/Twist`.
Подписчик: нода `/turtlesim`.

Сообщение Twist состоит из двух векторов:

- `linear` — линейная скорость с полями `x`, `y`, `z`;
- `angular` — угловая скорость с полями `x`, `y`, `z`.

В опыте отправлялось `linear.x = 1.0` для движения вперёд
и `angular.z = 0.5` для поворота. Остальные поля имели значение 0.

## Поза черепахи

Полное имя топика: `/turtle1/pose`.
Тип в установленной ROS 2 Jazzy: `turtlesim/msg/Pose`.
Издатель: нода `/turtlesim`.

Поля Pose:

- `x`, `y` — координаты черепахи;
- `theta` — её направление;
- `linear_velocity` — текущая линейная скорость;
- `angular_velocity` — текущая угловая скорость.

`/cmd_vel` в опыте тоже имел тип `geometry_msgs/msg/Twist`,
но это отдельный топик: у него был издатель и не было подписчика.
Для доставки должны совпадать и тип сообщения, и полное имя топика.
